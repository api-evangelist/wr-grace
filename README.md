# W. R. Grace

W. R. Grace & Co. is a global producer of specialty chemicals and specialty materials, providing catalysts and process technologies to petroleum refiners, petrochemical manufacturers, and other industrial customers. Grace operates in two segments: Catalyst Technologies (FCC catalysts and additives) and Materials Technologies (silica-based engineered materials). Grace's Fine Chemical Manufacturing Services (FCMS) division develops and manufactures active pharmaceutical ingredients (APIs) as a CDMO.

W. R. Grace does not offer a public software developer API. This repository documents the company's digital presence, domain vocabulary, and linked data context for API catalog purposes.
